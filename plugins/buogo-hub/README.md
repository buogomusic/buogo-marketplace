# BUOGO Hub

Hub central de carreira do BUOGO (@buogomusic). Reune marca, producao musical e estrategia num plugin so. Complementa o **buogo-reel-engine**, que cuida da producao de conteudo (reels, captions, rollout).

## Skills

| Skill | Pra que serve | Frases gatilho |
|---|---|---|
| **buogo-brand** | Aplica e audita a identidade de marca em qualquer peca | "ta na cara do BUOGO?", "isso passa no filtro?", "revisa essa peca" |
| **buogo-track** | Ideias de track, conceito de drop, sample digging | "ideia de track", "to travado", "que sample procurar" |
| **buogo-production** | Workflow de producao no Ableton, mix, finalizacao | "como mixo isso", "meu drop ta sem peso", "duvida no Ableton" |
| **buogo-career** | Estrategia macro: release anual, metas, label, A&R | "plano de lancamento do ano", "que label mando", "minhas metas" |

## Integracoes

- **Splice** (buogo-track): busca de samples por descricao quando o conector estiver ativo.
- **Ableton Knowledge** (buogo-production): consulta manual e tutoriais quando o conector estiver ativo.

Ambas sao opcionais. As skills funcionam sem elas, so ficam mais fortes com elas.

## Regras transversais

- Toda sugestao musical ou criativa sai com 3 referencias, uma ideia tirada de cada.
- Tudo passa pelo filtro de marca: se qualquer produtor poderia ter feito, nao serve.
- Tom direto, sem hifen, sem enrolacao.

## Instalacao

No Claude Code: `/plugin install buogo-hub` apos adicionar o marketplace, ou instale o arquivo `.plugin` direto.

Versao 0.1.0
